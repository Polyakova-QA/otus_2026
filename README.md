# Анализатор access.log

Скрипт `log_analyzer/log_analyzer.py` разбирает логи веб-сервера и собирает по каждому файлу статистику:

- общее количество запросов;
- количество запросов по HTTP-методам: GET, POST, PUT, DELETE, OPTIONS, HEAD;
- топ-3 IP-адресов по количеству запросов;
- топ-3 самых долгих запросов (метод, URL, IP, длительность, дата и время).

Каждый файл читается построчно за один проход, поэтому большие логи не загружаются в память целиком.

## Формат лога

```
%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d
```

Пример строки:

```
109.169.248.247 - - [12/Dec/2015:18:25:11 +0100] "GET /administrator/ HTTP/1.1" 200 4263 "-" "Mozilla/5.0 (Windows NT 6.0; rv:34.0) Gecko/20100101 Firefox/34.0" 7269
```

## Запуск

Нужен Python 3.7+, сторонние библиотеки не требуются.

```bash
# один файл
python3 log_analyzer/log_analyzer.py logs/access.log

# все .log-файлы в директории
python3 log_analyzer/log_analyzer.py logs

# справка
python3 log_analyzer/log_analyzer.py --help
```

Если передана директория, обрабатываются все файлы с расширением `.log` внутри неё (без вложенных папок).

## Результат

Для каждого лог-файла:

- статистика выводится в терминал;
- сохраняется отдельный json-файл в папку `results/` с тем же именем: `logs/access.log` → `results/access.json`.

Пример:

```json
{
    "top_ips": {
        "193.106.31.130": 235209,
        "198.50.156.189": 167812,
        "5.112.235.245": 166722
    },
    "top_longest": [
        {
            "ip": "62.93.172.245",
            "date": "[23/Dec/2015:07:27:57 +0100]",
            "method": "POST",
            "url": "-",
            "duration": 10000
        }
    ],
    "total_stat": {
        "GET": 2247848,
        "POST": 918794,
        "PUT": 70,
        "DELETE": 1,
        "OPTIONS": 39,
        "HEAD": 49971
    },
    "total_requests": 3216723
}
```

Полный результат обработки `access.log` лежит в `results/access.json`.

## Особенности

- В поле `url` записывается Referer, как в образце из задания.
- Учитываются экранированные кавычки `\"` внутри Referer и User-Agent.
- Строки, которые не подходят под формат, входят в `total_requests`, но в остальной статистике не участвуют. Поэтому `total_requests` совпадает с `wc -l`.
- При равной длительности в топ попадают запросы, которые встретились в файле раньше.
